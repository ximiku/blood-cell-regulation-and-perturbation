# 第 3 阶段统计方法

观测单位为 11,922 个共同基因，预测变量为 2,717 个 L1000 过表达扰动谱。21 个目标分别建模，响应采用目标减 HSC 的输入尺度差值；mDC 单列附加目标。

固定种子 20261107，外层五折划分由所有目标共享。每个外层训练集合中，再以种子 20261107 + 外层编号（1–5）生成三折内层划分。全数据最终模型使用种子 20261107 的三折调参，完整索引保存于 data/splits。

每个训练折分别计算 X 的列均值/总体标准差和 y 的均值/总体标准差。标准化后的 Lasso 目标函数为平方误差之和除以 2n，加 λ 乘系数绝对值之和。λmax = max|Xᵀy|/n，由当前训练折计算；50 个相对强度从 1 至 0.001 等比取值。各内层折以其自身 λmax 构建同一相对路径，在验证基因上还原至输入单位评价 MSE。

最低误差选择采用三折 MSE 均值最小值。1-SE 选择采用均值不超过最小均值加该点标准误的最大相对惩罚，标准误为三个折 MSE 的样本标准差除以 √3。两套参数在外层完整训练集重拟合，各自预测同一外层留出基因。均值基线仅使用相应外层训练 y 的均值。

主要指标由合并折外预测计算 R²、RMSE、Pearson 和 Spearman；另保存每折结果。所有基因各有一次留出预测。候选解释采用全数据重新调参的 1-SE 模型，保存全数据最低误差模型和完整路径。标准化系数表示预测变量增加一个训练标准差时响应改变的标准差单位；另保存输入单位系数、截距和每个 X 标准差对应的响应单位变化。

活跃扰动阈值为标准化系数绝对值大于 10⁻⁶，并另记录严格非零数。TF 初筛采用冻结的 TF 资格，按全数据系数绝对值排序、保留方向，每个目标至多展示 10 个。外层五次选择比例用于记录折间表现；第 4 阶段才计算预定的 100 次子抽样选择频率。

单扰动 Pearson/Spearman 排序采用全部共同基因，是同一数据内的描述性参照，未作为折外性能指标。正负方向与绝对相关排序均保留。

当前基因留出设计评价表达差异的重建能力；完整基因及 TF 候选的生物学讨论将在多模型、landmark、自身读出排除与重采样结果完成后展开。

Lasso 目标函数和 API 依据 [scikit-learn 官方文档](https://scikit-learn.org/1.5/modules/generated/sklearn.linear_model.Lasso.html)；加速求解器依据 [Celer 官方文档](https://mathurinm.github.io/celer/generated/celer.celer_path.html)。版本、收敛阈值和迭代单位记录在配置与 solver_diagnostics 中。

正式数值实现采用双精度的加速近端梯度法及自适应重启，批量处理共享训练折中的独立目标。每个目标仍有独立惩罚参数和收敛证书，最小化同一 Lasso 目标函数。平滑项 Lipschitz 常数由标准化 Gram 矩阵最大特征值确定；每个训练折中的对偶可行点由残差及最大相关约束构造。逐模型原始目标减对偶目标不超过 10⁻⁴×标准化 y 二阶矩，并在汇总时从原始训练行独立重算选定模型的证书。另使用更严格阈值的标准 scikit-learn Lasso 进行数值交叉核验。

算法背景：[Beck 与 Teboulle，FISTA](https://epubs.siam.org/doi/10.1137/080716542)、[O’Donoghue 与 Candès，自适应重启](https://link.springer.com/article/10.1007/s10208-013-9150-3)。正式 GPU 执行和逐路径记录保留在 results/lasso_gpu_paths 与 logs 中；CPU 实现试运行及连接排错写入工作日志。
